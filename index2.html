Python 語法教學：從入門到實務應用

Python 是一門簡潔、易讀、適合快速開發的程式語言，廣泛應用在自動化、資料分析、AI、網站後端與工具開發中。 對初中階開發者來說，掌握核心語法與程式設計思維，可以顯著提升開發效率與可維護性。

一個簡單範例

name = "Alice"
age = 25

if age >= 18:
    print(f"{name} 已成年")
else:
    print(f"{name} 尚未成年")

1. 基礎語法

變數與資料型別

Python 不需要明確宣告型別，變數可以直接賦值。這使得語法更簡潔，對初學者很友善。

  • 整數：int
  • 浮點數：float
  • 字串：str
  • 布林值：bool
  • 列表：list
  • 字典：dict
age = 28
price = 99.5
name = "Python"
active = True
skills = ["Python", "SQL", "Git"]
profile = {"name": "Alice", "age": 28}
Python 的程式碼區塊使用縮排（Indentation）來表示區塊，例如 if、for、def，這點是 Python 最重要的特徵之一。

2. 流程控制

條件判斷

if 用來處理條件分支，能依據不同狀態採取不同邏輯。 

score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")

迴圈

迴圈常用來重複處理資料。Python 常見的迴圈有 for 和 while。 

for i in range(1, 5):
    print(i)

count = 0
while count < 3:
    print(count)
    count += 1

3. 函式（Function）

函式的好處

函式讓程式碼更模組化、可重用，能將重複邏輯抽離出來，降低維護成本。

  • 名稱清楚且具語意
  • 減少重複程式碼
  • 方便測試與除錯
  • 提升可讀性
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8
函式的參數可以有預設值，像 def greet(name, message="Hello"): 這種設計可讓呼叫者更靈活。

4. 資料結構

列表 List

用來儲存有序資料，適合做陣列式處理。

nums = [1, 2, 3]
nums.append(4)

字典 Dict

用 key-value pairs 儲存相關資訊，常用於設定與資料表述。

user = {"name": "Bob", "age": 30}print(user["name"])

元組 Tuple

不可變資料結構，常用於固定值或避免意外修改。

point = (10, 20)

5. 進階概念

類別與物件

Python 支援物件導向程式設計（OOP），可以用類別來封裝資料與行為，適合大型專案與模組化設計。 

class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hello, {self.name}!"

p = Person("Tom")
print(p.greet())

例外處理

程式執行時可能出現錯誤，使用 try/except 可避免整個程式崩潰。 

try:
    value = int("abc")
except ValueError:
    print("輸入不合法")

6. Python 的實務建議

  • 保持程式碼簡潔： Python 強調可讀性，避免過度複雜的邏輯。
  • 命名要清楚： 例如使用 user_name 而不是 u。
  • 善用虛擬環境： 例如 venv 或 conda，可避免套件版本衝突。
  • 寫測試： 對核心功能使用單元測試，提升可靠性。
  • 閱讀風格指南： 遵循 PEP 8 可提升團隊協作效率。

7. 小結

Python 的優勢在於它的語法簡潔、閱讀性高，且在實務開發中能快速建立原型與工具。若你已理解變數、條件判斷、迴圈、函式與物件導向基本概念，接著就可以開始做專案練習，例如：自動化腳本、API 串接、資料清理、簡單網站後端等。

進階學習的下一步可以是：模組化設計、錯誤處理、資料結構與演算法、Python 套件使用、以及 Web / Data / AI 相關應用。
